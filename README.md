# Technical Learning & Daily Work Documentation Journal

An interactive personal technical learning journal, development tracker, and multi-project knowledge base.

---

## 🌟 Key Features

- **📅 Interactive Calendar & Timeline**: Gregorian visual tracker starting from **10 August 2026**.
- **📋 3-Layer Architecture**:
  1. **Layer 1 (Calendar)**: Quick daily previews, task counts, and monthly progress summaries.
  2. **Layer 2 (Daily Reports)**: Detailed day modal breakdowns with tasks, tech badges, timeline, and problems & solutions.
  3. **Layer 3 (Deep Knowledge Base)**: Comprehensive technical articles with code blocks, architecture diagrams, callouts, and comparisons.
- **📚 Domain Coverage**:
  - **Backend & Web APIs**: Django 6.1, DRF, Serializers, Models, Service Layer, SQLite.
  - **Email Architecture**: SMTP, TLS (Port 587), EmailMultiAlternatives, CID (Content-ID) Logo Embedding.
  - **Cloud Computing**: AWS vs Azure vs GCP (3-level comparison, 26-category service matrix, FinOps pricing models, Kubernetes EKS/AKS/GKE, Serverless).
- **⚠️ Errors & Post-Mortems Hub**: Real-world root-cause analyses and solutions.
- **🔍 Global Search & Filter (`Ctrl+K`)**: Live instant search across all topics, daily logs, and errors.
- **🌙 Dark / Light Mode**: Theme toggle with persistent `localStorage` preference.

## 🚀 Live Hosting on GitHub Pages

1. Create a repository on GitHub named: **`<your-username>.github.io`** (or `tech_portfolio_docs`).
2. Push this repository to GitHub:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Technical Learning & Documentation Portal"
   git branch -M main
   git remote add origin https://github.com/<your-username>/<your-username>.github.io.git
   git push -u origin main
   ```
3. Your website will be live automatically at:
   **`https://<your-username>.github.io`**
